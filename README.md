# Zenith
---
## Descripcion.

Este proyecto principalmente esta planteado para la materia de Desarrollo Web 2. Se trata de un habit tracker el cual te pueda ayudar a mantener constancia en tus hábitos para lograr tus metas. 

El proyecto se encuentra en constante desarrollo por lo que esta sujeto a cambios. 

## Tecnologias.

### Frontend.
- Angular 21

### Backend.
- Node.Js
- Express

### Base de datos
- PostgreSQL
